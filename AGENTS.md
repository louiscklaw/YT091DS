# AGENTS

- **Overview:** Simple static HTML application for learning Chinese herbs.
- **Entrypoint:** `docs/index.html` provides navigation to learning modules (`docs/chapter_2_mc.html`, `docs/herbs_recognition.html`).
- **Development/Testing:** Static site with no build step, package manager, or automated test suite. Preview by opening `docs/index.html` in a browser or serving the `docs/` directory.
